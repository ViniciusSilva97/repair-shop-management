# Registros de decisão arquitetural

ADRs preservam o contexto de decisões que afetam várias versões.

## Quando criar

- nova dependência estrutural;
- mudança de banco ou modelo de execução;
- decisão de segurança ou criptografia;
- estratégia de instalação, atualização ou licença;
- integração fiscal;
- mudança incompatível de dados ou API.

## Convenção

```text
NNNN-titulo-curto.md
```

Estados: proposto, aceito, substituído ou rejeitado.
