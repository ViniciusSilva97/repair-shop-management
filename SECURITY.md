# Política de segurança

## Estado do projeto

O projeto está em planejamento e ainda não possui uma versão comercial suportada.

## Relato responsável

Não abra uma issue pública com credenciais, dados pessoais, XMLs reais, bancos de clientes ou detalhes que facilitem exploração.

Use o canal privado de segurança do repositório quando ele estiver habilitado. Até a definição do canal definitivo, comunique o proprietário do repositório diretamente pelo GitHub sem anexar dados de clientes.

Inclua somente:

- componente e versão afetados;
- impacto provável;
- passos mínimos com dados fictícios;
- evidência sanitizada;
- mitigação conhecida, se houver.

## Prioridade

Vulnerabilidades envolvendo perda de dados, acesso indevido, atualização adulterada, restauração, XML malicioso, caixa ou estoque bloqueiam uma liberação até correção ou mitigação formal.

## Dados de teste

É proibido adicionar ao repositório:

- bancos de oficinas reais;
- CPF, CNPJ, telefone ou endereço de clientes reais;
- XML fiscal real não anonimizado e autorizado;
- senhas, tokens, certificados ou chaves privadas;
- pacotes de suporte sem sanitização.
